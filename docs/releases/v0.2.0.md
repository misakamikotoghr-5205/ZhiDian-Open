**指一下，问一句；选中了，就能办事。模型和工具都跑在你自己的电脑上。**

这是「指点」`v0.2.0` 版本，围绕真实桌面使用体验完成了全面的**反人类交互整改**与**高频办公/截图能力补全**。完整的说明、实测数据和已知限制见仓库的 `README.md`。

## 下载哪个文件

| 系统 | 文件 | 打开方式 |
|---|---|---|
| Windows（x64） | `Zhidian-windows-x64.zip` | 解压，双击 `Zhidian.exe` |
| macOS（Apple 芯片） | `Zhidian-macos-arm64.zip` | 解压，把 `Zhidian.app` 拖进"应用程序"再打开 |
| Linux（x64，X11 会话） | `Zhidian-linux-x64.tar.gz` | 解压，运行里面的 `Zhidian` |

不需要安装，也不需要装 Node。Intel 芯片的 Mac 暂时没有包，请按 README 从源码运行。

## v0.2.0 更新亮点

### 1. 全面消除「反人类」操作摩擦
- **划词不挡路**：默认改为 **轻量小浮标（32×32）**，鼠标移上去或点击才展开完整动作面板；空闲态按 `Esc` 立即收起；新增 **前台应用黑名单**（一键屏蔽 VS Code、Cursor、终端等开发工具里的划词打扰）。
- **指点手势顺滑直觉**：**左键单击立即唤出提问框**（不再强制误钉 `@1`）；**右键切换固定 / 取消固定**（对已钉区域再按右键即取消）；新增 **`[` / `]` 键**、面板内 **`范围 −` / `+` 按钮** 以及 **触控板自然滚动方向开关**。
- **面板自由拖拽 + Markdown 富排版 + 多轮历史保留**：提问框、回答气泡、悬空快照和动作面板均可拖拽移开；回答支持安全 DOM **Markdown 排版**（标题、列表、表格、代码块一键复制）；追问自动保留上一轮进可折叠历史记录；`Ctrl/Cmd+K` 一键新开话题。
- **按键直接录制热键 + 已装模型一键清理 + 拖拽文件即办**：热键输入框点一下直接按组合键录制；已下载的本地模型支持在设置页二次确认删除或打开目录；设置页支持直接拖入文件或一键处理当前剪贴板内容。

### 2. 新增高频桌面与办公功能
- **框选快捷工具链**：不调模型也能直接 `复制截图`（`Ctrl/Cmd+C` 无损 PNG 进剪贴板并回原窗口）、`保存图片`（`Ctrl/Cmd+S`）或一键 `提取文字`（OCR 识别完成后自动写入剪贴板）。
- **PDF 增强**：新增 **提取指定页**（支持 `1-3, 5, 末页` 及倒序提取，面板内联输入页码）、**顺时针旋转 90°**、**压缩扫描件 PDF**。
- **现代图片格式与 WebP 导出**：新增一键 **转成 WebP**；支持 `.avif`、`.svg`、`.ico`、`.jfif`（以及 macOS 原生转换 `.heic`/`.heif`）。
- **多语种翻译与自动复制**：`翻译` 按钮旁可直接选择目标语言（自动中英互译 / 中 / 英 / 日 / 韩 / 法 / 德）；翻译、润色、识别文字结果自动复制到剪贴板；新增开机自启开关。

## 第一次打开

1. **系统会拦一下。** 这些包没有代码签名。Windows 的 SmartScreen 点"更多信息 → 仍要运行"；macOS 在"系统设置 → 隐私与安全性"里点"仍要打开"，或者在终端执行 `xattr -cr /Applications/Zhidian.app`。
2. **下载一次模型。** 设置窗口里点"下载并安装"（0.74 GB），之后可以断网使用。办公动作和框选截图复制不需要模型，打开就能用。
3. macOS 会询问"屏幕录制"权限（指着问需要它），以及"辅助功能""自动化"权限（选中就办需要它们）。

然后按 <kbd>Alt</kbd> + <kbd>`</kbd> 或 <kbd>F8</kbd> 开始指。
