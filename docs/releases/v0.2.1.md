# 指点 v0.2.1

本次为 v0.2.0 的修复版本，重点修正文档转换、截图交互和模型下载中的边界问题。

## 修复内容

- Markdown 转 PDF 的打印窗口禁止加载网络资源，保留本地图片和内嵌图片支持。
- 生成 PPT 时保留长代码和表格的完整内容，并提示内容缩减；修复纯文本换行处英文单词粘连。
- 展开历史回答后更新鼠标交互区域，避免新增区域的点击穿透到其他应用。
- 新话题或关闭回答时取消旧指示标记，避免动画队列重新显示已清除的标记。
- 取消固定目标后，快捷截图使用当前框选区域。
- 下载模型期间重新打开设置，正确恢复下载状态及取消按钮。
- 复用已下载的模型和运行时文件前检查 SHA-256，拒绝同尺寸的损坏文件。
- LibreOffice 缺少 PDF 导入组件时，PDF 转 Word 明确报错，不再把 PDF 原始字节当作转换成功的文档保存。

## 下载

| 系统 | 文件 |
|---|---|
| Windows x64 | `Zhidian-windows-x64.zip` |
| macOS Apple 芯片 | `Zhidian-macos-arm64.zip` |
| Linux x64（X11） | `Zhidian-linux-x64.tar.gz` |

解压后启动即可，无需安装 Node。首次使用本地模型仍需下载模型；办公文件转换不需要模型。包没有开发者证书签名，首次启动可能需要在系统安全设置中允许运行。详细使用方法见 README。
