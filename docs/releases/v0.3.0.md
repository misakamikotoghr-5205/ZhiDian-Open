# 指点 v0.3.0

**本地预览包已生成，GitHub Release 暂未发布。** GitHub Actions 因账户预算限制未能启动，Release 附件上传返回 401；Windows 原生测试及本次 macOS 构建尚未完成。Windows x64 和 Linux x64 包已在开发会话中保留并提供下载；Linux 包通过启动自检，Windows 包尚未在 Windows 实机上验证。恢复 Actions 额度并通过全部检查后，可由发布流程生成和公开正式安装包。

这次升级把 F8 从截图入口扩展为“当前应用”工作台：读取系统确认的上下文和真实文件文字，直接选择本地动作，或先检查模型提出的方案再执行。同时重做设置界面，支持多 API 连接、已有本地模型、通用 MCP 客户端和三种文档样式。

## 新功能

- **F8 当前应用**：在叠加层取得焦点前读取前台应用、窗口标题、系统提供的文件路径、选中文字和可用控件。面板显示来源与限制，可以切换到原有屏幕问答。
- **真实文件与动作方案**：读取已保存文档的有界文字摘录，交给所选本地或 API 模型回答；需要操作时只允许选择本次提供的动作，最多六步，显示参数并等待用户点击执行。方案绑定本次快照、两分钟过期、只能执行一次；执行前检查文件和控件身份。
- **Windows 原生控件**：通过 UI Automation 为支持的控件提供点击、聚焦、填写和滚动；读取资源管理器选区，以及 Office 可访问的已保存本地文档路径。密码控件跳过，不承诺支持所有应用。
- **多 API 连接**：Claude / Anthropic、OpenAI、Gemini、DeepSeek、通义千问 / 百炼、硅基流动、OpenRouter 与自定义预设自动填写地址和初始模型。支持读取模型列表、独立命名配置、切换、另存、重命名和删除；旧配置自动迁移。每个连接分别保存密钥并绑定主机，密钥保护沿用系统钥匙串；Linux 没有钥匙串时仍明确提示仅靠文件权限保护。
- **已有本地模型**：Ollama、LM Studio 地址预设与模型列表，可直接连接已安装的 8B 等模型。按服务元数据标注文字 / 视觉能力，未知时可手动指定；纯文字模型可以处理应用文字任务，截图问答需要视觉模型。
- **通用 MCP**：设置提供 Cursor、VS Code / Copilot、Claude Desktop、通用 HTTP 与 stdio 配置。保留截图读取与指回屏幕，新增当前应用读取及动作建议；建议必须在指点中由用户执行，没有直接执行工具。
- **界面更新**：浅色工作面板、蓝色强调、清晰的“当前应用 / 看屏幕”入口，以及带侧边导航和连接卡片的设置窗口。
- **三种文档样式**：商务蓝、极简灰、暖调纸，应用于生成 PPT、Word 一键排版、导出 Excel 和内置 HTML 排版路径生成的 PDF。Excel 使用对应配色表头，冻结首行，并为有数据的表格添加筛选。原有 PDF、图片转 PDF 和 LibreOffice 保留版式转换不会被统一重排。
- **修复浮窗无法点击或点击后消失**：Windows 空闲浮窗在鼠标进入可交互区域时允许正常取得焦点，及时更新点击区域；用户正在操作浮窗时，不再被前台应用失焦产生的空选区通知移除按钮或输入框。

## 内容范围与限制

- 默认本机处理，API 默认关闭。屏幕问答发送所固定的截图；应用任务使用应用名、标题、选中文字、文件名、控件标签和文件文字摘录。启用网络模型或远程模型服务后，这些任务内容会交给所选服务。
- 应用任务最多摘录前五个文件，每个最多 10,000 字符、合计最多 22,000 字符；超过 20 MB 的文件不读文字，PDF 最多前八页，选中文字最多 8,000 字符。文件摘录不包含未保存编辑、图片或完整布局，也不等于读完了整份文档。
- Windows 控件能力受应用 UIA 支持与权限限制；提权窗口、自绘控件可能不可用。macOS 当前读取辅助功能上下文和 Finder 选区，需要相应权限，没有控件执行；Linux / X11 当前读取前台身份与标题，文件需手动选择 / 拖入，文字可使用原有选区面板。Wayland 不支持这套前台读取。
- 不支持任意应用自动化；模型只能提出已列出的动作。多步操作不会自动回滚，后续失败时已完成的步骤仍然有效。
- 内置 Word 转 PDF 会重排版面，复杂文档建议使用 LibreOffice；扫描件 PDF 的文字提取不含 OCR。小模型仍可能理解错误，执行前请检查方案。
- 新增设置、协议、文件摘录和方案流程包含本地测试服务及测试快照覆盖；这不代表已验证所有真实 API 服务、厂商 MCP 客户端或桌面应用。新增 macOS 原生读取尚未在本次 Linux 开发环境中实测，Windows 原生测试及各平台结果以本版本 CI 为准。
