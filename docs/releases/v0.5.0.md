# 指点 0.5.0

Windows 离线办公版本。F8 打开约340px的小卡片；基本设置保留语音开关和折叠高级设置。移除2B中档和通用窗口控制入口。

截图鼠标操作调整：左键点击确认截图，左键拖拽继续框选；右键改为取消截图，Esc取消继续保留。取消后松开左键或收到延迟截图结果，不会重新生成截图。

模型选择修复：高级设置手动指定0.8B或4B时优先尊重选择，只有“自动选择”才按内存推荐。保存模型目录不会改变所选档位。支持直接选择含GGUF的文件夹或其上级存储目录，并显示当前模型文件路径；指定模型缺失时明确提示，不静默换成0.8B。

下载入口恢复并固定保留在「高级设置 → 本地模型 → 下载模型」。支持0.8B和4B、下载源、进度、取消与重试；无模型包可通过此入口补齐模型、视觉投影器和运行时，完整离线包仍直接使用内置文件。下载不改变自动/手动使用模型的设置，首次打开不自动下载。

## 文件与模板
- 框选桌面或资源管理器文件图标即可绑定真实文件，无需预选或拖入；路径由Windows Shell确认。
- 同名、虚拟图标、过期快照及文件变化时不猜路径、不静默执行部分选择。
- PDF文字优先写入可编辑PPT模板；扫描页明确标注不可编辑。
- 长宽表格完整分页，重复表头和关键列。Word/PDF/PPT/表格共用主题规则。
- 小模型开放8项基础办公动作，大模型开放20项；显示和执行端共同限制。

## 离线模型与实际训练
软件目录包含0.8B/4B Q4模型、视觉投影器、办公LoRA及llama.cpp运行时。启动不下载、不把模型复制到C盘。按总内存和可用内存自动选择档位，扩展目录可在高级设置更改。

本轮在RTX3060 Laptop GPU完成0.8B的rank8 LoRA：96步、约329秒、峰值显存约1856MiB。训练集368条合成中文办公任务，独立措辞留出集76条，没有使用用户文档。

数据仅验证有限动作规划，不代表通用办公、OCR或排版能力。仍有PDF提取/拆页等混淆，保留确定性动作按钮和执行前方案确认。4B是固定版本原始Q4，未进行本轮LoRA训练。

## 使用与发行包
解压完整目录后双击 `Zhidian.exe`，不要单独移动exe。GitHub分卷发行包需下载全部 `.7z.001`、`.002` 等分卷，放在同一目录，用7-Zip从第一卷解压。分卷是为了满足单个附件大小限制，解压后的软件不需要下载模型。

| 附件名称 | 说明 |
|---|---|
| `Zhidian-v0.5.0-windows-x64.7z.001` ~ `.003` | **Windows x64 完整离线包**（由 GitHub Actions 自动构建校验，内置 Qwen3.5 0.8B/4B Q4 权重、视觉投影器、Office/Pointer 双 LoRA 与 `llama.cpp` 运行时，解压即用） |
| `office-small-lora.gguf` / `office-adapter.json` | **自训办公动作规划适配器（3.4 MB）**（面向 `Qwen/Qwen3.5-0.8B`，76 题留出集严格 JSON 率 100%，动作+参数准确率 89.5%） |
| `zhidian-pointer-qwen3.5-0.8b.gguf` | **自训屏幕副光标一趟视觉定位适配器（12.2 MB）**（面向 `Qwen/Qwen3.5-0.8B`，单趟同时输出回答与 UI 元素坐标） |

语音识别仍需配置本机Whisper兼容服务或云端API，语音权重不在离线包内。扫描PDF保留图片页，任意外部PPT模板的占位符映射尚未提供。发布流水线状态以GitHub Actions实际结果为准。
