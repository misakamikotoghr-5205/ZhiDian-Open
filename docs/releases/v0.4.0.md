# 指点 v0.4.0

**v0.4.0 预览版历史发布记录（非 Draft）。** Release Assets 提供 Windows x64、Linux x64 安装包和 `SHA256SUMS.txt`，远端文件摘要与本地一致。安装包在开发环境构建；Linux 解压包通过启动自检，Windows 包尚未实机验证，未提供新的 macOS 包。跨平台 CI 仍受 Actions 预算限制，具体验证范围见下文。

这次升级增加可选语音输入：说话后先得到可编辑草稿，检查后再发送给聊天模型或当前应用工作流。

## 新功能

- **麦克风输入**：当前应用任务框和屏幕提问框提供入口，支持点击开始 / 停止、按住说话后松开结束。面板显示录音状态、时长、处理位置及声音反馈；遵循系统“减少动态效果”偏好。
- **交互动效**：启动和录音时显示蓝紫渐变光球与音量波形，转写时切换流动光环，文字写入后短暂高亮；面板淡入与按钮涟漪保持点击区域稳定。
- **草稿保留**：识别结果插入现有输入，不自动提交问题，不自动执行操作。录音或转写可以取消，迟到的结果不会覆盖已取消的草稿。
- **独立语音设置**：OpenAI、Groq、本地 OpenAI 兼容服务和自定义预设；地址、语音模型、识别语言、密钥与聊天配置分开管理。服务地址必须提供 `/audio/transcriptions` 音频接口。
- **有界录音与转写**：每段最长 60 秒，到时自动结束录音并开始识别；主进程校验 WAV 格式、真实采样时长和 4 MiB 大小上限。请求超时、权限拒绝、设备不可用、服务错误都有提示。
- **显式麦克风会话**：仅在用户开始录音后授予当前叠加层音频权限；停止、取消、退出或设置改变时清理录音 / 请求。拒绝重定向，密钥绑定保存时的服务主机，报错不显示密钥或原始服务响应。

## 使用与内容范围

先在设置 → **语音输入**选择服务并启用，再按 F8 点击输入框旁的麦克风。录完后检查转写文字，按发送才开始聊天或任务规划；动作方案仍需检查后执行。

语音识别与聊天模型分别路由。选择云端语音时，录音会发送给语音设置中的主机，即使聊天模型在本机运行；选择本地语音但使用云端聊天时，任务发送后文字和对应上下文仍会交给聊天服务。应用以内存中的 PCM 处理录音，以 16 kHz 单声道 WAV 转写，不主动保存音频文件。取消录音不会上传；取消已开始的转写会中止请求，但不能撤回已经发出的音频。

## 限制与验证范围

- 本地语音要求用户已有支持 OpenAI 音频转写协议的服务，例如提供兼容接口的 Whisper 服务。本版没有内置 Whisper 下载或安装器；`http://127.0.0.1:8000/v1` 是可编辑预设，并不会自动启动服务。已有 8B、Ollama 或 LM Studio 聊天接口本身不等于语音识别接口。
- 云端语音需要账户权限和对应语音模型，费用由服务商收取。没有系统钥匙串的 Linux 环境，已保存密钥仍仅受文件权限保护。
- Windows 需允许“麦克风访问”和“桌面应用访问麦克风”；macOS 需允许指点访问麦克风；Linux 需要可用录音设备。没有后台监听、唤醒词或语音自动执行功能。
- 验证包含 WAV / 配置校验、独立密钥、multipart 请求、取消、超时和错误处理；交互测试使用 Electron 模拟麦克风与本机测试服务。不能据此推断真实 Windows / macOS 麦克风、真实服务识别准确率、方言及嘈杂环境已验证。
- 原有应用上下文、UIA 控件和文档转换限制继续适用：不支持任意应用自动化，不读取文件中未保存的修改，跨平台能力不同，详见 README。
