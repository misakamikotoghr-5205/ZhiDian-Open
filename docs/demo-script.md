# 三分钟演示稿

一句话：**「指点」给鼠标指针装上一个跑在本机的小模型。指一下，问一句，AI 再用它自己的光标指回来。不联网，普通笔记本就能跑。**

## 上台前（提前一天做完）

1. 在**要演示的那台电脑**上跑 `npm install && npm run setup`，然后 `npm start` 完整走一遍下面的流程。别的电脑上跑通不算。
2. macOS：系统设置 → 隐私与安全性 → 屏幕录制，给 Electron（或打包后的 指点）授权，然后**重启应用**。
3. 打开设置窗口，确认"本地模型"显示"已就绪"，热键显示"已生效"。热键被占用就换一个。
4. 准备演示内容：`test/e2e/stage.html` 用浏览器打开就是一个现成的舞台（商品卡片、报错弹窗、表格、带错误的代码）。窗口用普通大小，不要全屏。
5. 投影用镜像模式，接上之后再走一遍。分辨率和缩放变了，热键进入时截的图也跟着变，要确认吸附框还对得上。
6. 录一段同流程的备份视频。
7. 上台前先问一个问题热身：模型第一次加载要几秒，之后就快了。

## 演示（三拍）

### 第一拍 · 断网，指一下（约 50 秒）

> "先把网断了。"（当众关 Wi-Fi）

按热键。鼠标移到报错弹窗上，**停住**，对话框自己弹出来。

> "我没有选中任何东西，也没有截图粘贴。鼠标停在哪，它就问哪。"

右键固定，左键点 **"下一步该点哪里？"**。回答流出来，紫色的 AI 光标飞到"重试"按钮上。

> "绿色是我的指针，紫色是 AI 的。它不只是告诉我，它指给我看。整个过程没有一个字节离开这台电脑。"

### 第二拍 · 两个目标（约 50 秒）

鼠标移到第一张商品卡，滚轮往上滚一格把范围扩到整张卡片，右键（@1）。移到第二张，右键（@2）。点 **"哪个更划算？"**。

> "'这个'和'那个'现在是两个有编号的东西。对话框里能看到将要读入的就是这两小块，一共几十 KB，是整个屏幕的百分之十几。"

回答里出现 @1、@2，AI 光标依次指向两处。

### 第三拍 · 它知道东西变了（约 40 秒）

按 Esc 回到页面，底部托盘里 @1、@2 还在。把页面滚动一下（或者改掉一个价格），再按热键。

> "我钉住的那块内容已经不在原来的位置了。它不会装作还在：这个引用被标成'悬空'，AI 不会再往现在的屏幕上指，只会指在当时的快照上。程序员都懂——悬空指针不能解引用。"

### 收尾（约 30 秒）

> "模型是 Qwen3.5 的 0.8B 版本，量化后 0.74 GB，纯 CPU。我们给它做了一个 LoRA，让它一趟推理同时给出回答和坐标，数字在这一页。"

放 `docs/benchmarks.md` 里的实测表（只放测过的数）。

## 被问到时怎么答

| 问题 | 回答 |
|---|---|
| 这不就是 Google Magic Pointer 吗？ | 它只在 Googlebook 上，回答和动作要交给云端的 Gemini，指一次就忘。我们在任何笔记本上离线跑，能记住多个目标，AI 还会指回来。（别说"Google 和微软没有本地的部分"：它们的识别是在本机做的，微软的 Click to Do 连几项文字动作也在本机，只是要 Copilot+ PC。） |
| 截两张图贴给大模型不也行？ | 贴过去的图没有屏幕坐标，所以模型指不回来；也不知道内容后来变了；而且要离开手头的应用。更重要的是图上传了。 |
| 0.8B 的模型能有多聪明？ | 读界面文字、找按钮、比两个数字够用，复杂推理不行。指针的作用正是把输入缩小到几百个 token，小模型才够用。想要更强可以在设置里换 2B 或 4B。 |
| 小模型答错了怎么办？ | 设置里可以接一个联网的大模型（默认关闭）。本机先答，不满意再点"联网重答"，只把这一个问题和框住的那一小块发出去，发之前界面上写明发到哪。演示时如果要展示这一步，请先用自己的密钥在这台电脑上试过：这条链路只对着假服务端测过。 |
| 为什么是冻结画面？ | 你看到的、算法分析的、交给模型的是同一帧；右键和滚轮也不会和底下应用自己的菜单冲突。 |
| 在 Mac / Windows 上呢？ | 用的是 Electron 的跨平台接口，没有原生模块。（只说你亲手验证过的平台。） |

## 出问题时

- 吸附框不对：直接**拖拽**框选，同样能固定。
- 模型卡住：Esc 重来，不要在台上调试。
- 热键没反应：托盘图标 → 开始指向。
- 实在不行：切备份视频，直说"现场环境出了问题，这是昨晚录的同一流程"。
