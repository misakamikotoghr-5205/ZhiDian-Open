VOICE INPUT

语音输入

把说的话转成文字，再决定是否发送。可以连接云端语音 API，也可以使用你自己的本机语音识别服务。

语音识别服务

配置自动保存，密钥单独保存

填写 OpenAI 兼容音频转写 API 的根地址，通常以 /v1 结尾，不包含 /audio/transcriptions。

录音处理位置

1开始说话

点击麦克风开始，再点一次停止；也可以按住说话，松开结束。

2检查转写文字

识别结果先放进输入框，你可以修改和补充。

3由你发送

确认内容后再发送给聊天模型，不会自动提问。

连接本机语音识别服务
  1. 先启动一个提供 OpenAI 兼容 /audio/transcriptions 接口的本地语音识别服务，例如兼容该接口的 Whisper 服务。
  2. 选择“本地 OpenAI 兼容服务”预设，按服务实际配置填写地址与语音模型名；不需要认证的本机服务可以不填密钥。
  3. 启用后，在提问框点击麦克风试说一句，先检查转写文字。音频使用 16 kHz 单声道 PCM WAV 格式。

已有的 8B 聊天模型负责对话，不等于语音识别模型。仅启动 Ollama / LM Studio 的聊天服务不能完成语音转写；这里需要单独提供音频转写接口。

热键

点击输入框后直接按下键盘组合键即可自动录制（按 Backspace 清空，Esc 取消）。截图模式：左键点击截图，左键拖拽框选，右键或 Esc 取消截图；滚轮或 [ ] 换范围，Ctrl+C 复制截图。

屏幕录制权限

macOS 需要这项权限才能看到你指着的内容。授权后请重新打开 指点。截屏只在你按下热键时发生，并且只在本机处理。
